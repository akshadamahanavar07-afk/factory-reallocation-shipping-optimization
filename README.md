# Factory Reallocation & Shipping Optimization

## Project Overview
This project develops a recommendation system for Nassau Candy Distributor to improve factory allocation and shipping efficiency.

## Objective
The main objective is to identify suitable factories for products by comparing shipping distances and recommending factory reallocations that can reduce transportation distance.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Data Analysis
- Machine Learning

## Key Features
- Factory recommendation
- Shipping distance comparison
- What-if scenario analysis
- Product-wise factory optimization
- Risk and impact analysis

## Dashboard
An interactive Streamlit dashboard is developed to compare current and recommended factory assignments.

## Dataset
The project uses historical Nassau Candy Distributor order data containing product, factory, region, shipping mode, sales, profit and shipping information.
